# Frame-by-frame pencil film in JavaScript — what worked, what didn't

Reference production: « Le gâteau de Mamie » (1080×1920, 3 fps, 20 s, 60 drawings). Source in `public/web/`.

## 1. Architecture (one pipeline, not eleven)
```
web/js/engine.js      seeded RNG, pencil ink(), colored-pencil paint(), unite(), chain(), ik(), paper, perspective P(X,Y,Z)
web/js/characters.js  person(design, pose) — whole pose redrawn; hands, heads, hair, back view; cat
web/js/scene.js       set as 3D volumes projected in one-point perspective + props (cm units at a world point)
web/js/film.js        exposure sheet, camera per shot, object continuity state, per-frame poses, drawFrame(i), cues
web/preview.html      requestAnimationFrame player (play/pause/restart/scrub/time/sound) using the SAME drawFrame
web/scripts/          render-frames.mjs (Playwright), export-video.sh (HTML | images | video → mp4/webm/mov/gif), make-sfx.py
```
Contract: `window.FILM = {ready,fps,frames,duration,init(canvas),drawFrame(i),seek(t),png(),sheet,cues}`.
Export = for each i: `FILM.drawFrame(i); FILM.png()` → PNG → FFmpeg. Never record real-time playback.

## 3. Drawing techniques that made the difference
1. **`unite(shapes)` = stroke all outlines at double width, THEN fill all shapes** (same winding, nonzero). Interior
   seams (elbow, wrist, neck/head/ears, hand/forearm) vanish and there is never a gap. This solved the brief's
   "remove the line between arm and forearm".
2. **`chain(joints, widths)`**: one closed outline around a Catmull-Rom spine (shoulder→elbow→wrist). Remove inner-side
   loops at sharp bends.
3. **Hair is an opaque shape that contains the whole top of the skull**, drawn after the face; bun/pigtails before the head.
4. **Pencil `ink()`**: resample every 5 px, low-frequency normal wobble + jitter, 2 passes (2nd lighter/thinner),
   pressure taper, overshoot on open strokes, closed loops start at a random point and overlap 4–12 %. Width 3.6 px.
5. **Colored pencil `paint()`**: opaque base (paper-mixed color, keeps occlusion correct) + hatching clipped to the
   shape **translated by a random 3–5 px** → coloring spills over one edge and leaves a light rim on the other.
6. Line widths are in screen px (`pxs()` reads the transform) so zoomed shots keep the same pencil.
7. Paper texture generated once with a fixed seed (registered to the paper), tooth + multiply on top, warm vignette.
8. **Perspective set**: `P(X,Y,Z)` with camera height 1.45 m; furniture as faces (`face()` subdivides edges so the wobble stays organic);
   sort draw items by Z. Characters drawn in local cm at `SC.at(X,0,Z)`; `W2L()` converts world object positions into a
   character's local space so hands land exactly on the bowl/tin/plate.
9. Seated kids behind a table: draw body before the table and **front arms after the table top** (`only:'noarms'|'arms'`).
10. Held objects: draw the prop in the "behind-hand" hook so the fingers overlap it; flat-palm carry draws the prop after.

## 4. Workflow that caught the real bugs
- Render 6–12 key frames → contact sheet → fix → full render (≈0.7 s/frame).
- **Crop at full resolution** around the action: thumbnails hid a finger pointing at the tablecloth instead of the cake
  (index bug: Y used as Z), arms hidden under the table, a spoon aimed at a child's face.
- Contact sheet cropped to the action zone (`qa/actsheet.py`), onion skins (`qa/qa.py`), consecutive-frame diffs
  (detect accidental cuts/duplicates), byte-identical re-render (determinism), ffprobe + OpenCV PSNR of the encoded MP4.
- Check: object continuity table (every prop has a location for every frame), hands never cover the face, characters never
  hidden at the key moment, camera keeps the action in the 9:16 safe zone (avoid right 12 % and bottom 20 %).

## 5. What did NOT work / pitfalls
- Setting the set width by eye: the oven ended up off-frame → compute screen x of key volumes for each camera.
- Rounded Catmull-Rom on 4-point rectangles → blobs ("speech bubbles"); keep sharp polygons for paper/frames.
- Too many props near the character → reach problems; lay out the table from the grandma's arm reach (≈ 0.85 m with lean).
- `grep -q` in a pipe with `set -o pipefail` breaks encoder detection in bash scripts.
- Playwright's Chromium cannot decode H.264: test `<video>` with WebM or a real browser; validate MP4 with ffprobe.
- Python signal sums of different lengths → pad.

## 6. Style used
Warm children's book: butter wall with tiny flowers, sage wainscot, terracotta checker floor, red gingham, mauve dress,
cream apron, primary accents (red, yellow, blue). Graphite #3b2f2a, paper #f6eedd. Faces: dot eyes with glint, arcs for
happy/closed, blush circles, tiny nose. Cartoon marks only (notes, call arcs, "!", hearts, sparkles, speed lines) — no text.

## 7. Commands
```bash
cd public/web && python3 -m http.server 8080                         # live preview
./public/web/scripts/export-video.sh public/web/preview.html out.mp4  # HTML → Chromium → FFmpeg (auto-installs Playwright)
./public/web/scripts/export-video.sh frames out.webm --fps 3          # image sequence
./public/web/scripts/export-video.sh out.mp4 out.mov                  # re-encode
python3 qa/qa.py                                                      # QA metrics + onion skins
```
